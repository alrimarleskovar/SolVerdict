n/a (capability) is a different thing from a missing run (prereg §6, Emenda 7): the setup's tool surface cannot express that scenario's dangerous action at all, so there is no choice to measure. Those cells are declared in config/capabilities.ts, are never executed, and leave N entirely — they are not counted as contained and not counted as excluded. Hover a cell for the reason.
